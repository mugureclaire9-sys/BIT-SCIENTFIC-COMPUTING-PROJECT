# BIT 2118 – SCIENTIFIC COMPUTING PROJECT

## 1. Introduction

This project contains practical implementations of scientific computing concepts using the Python programming language.

It covers numerical methods, mathematical computations, matrix operations, equation solving, interpolation, numerical integration, optimization and simulation.

The project demonstrates how Python libraries can be used to solve mathematical and scientific problems through programming.

## 2. Project Objectives

The main objectives of this project are:

- To understand the application of scientific computing concepts.
- To implement numerical methods using Python.
- To perform mathematical and scientific calculations using Python libraries.
- To compare results obtained from original and modified input data.
- To interpret numerical results and understand their real-world applications.
- To develop practical programming and problem-solving skills.

## 3. Technologies and Libraries Used

The project uses the following technologies:

- **Python:** Main programming language.
- **NumPy:** Numerical calculations and array operations.
- **SciPy:** Scientific and numerical computations.
- **Matplotlib:** Data visualization and plotting where required.
- **Timeit:** Measuring program execution time.
- **Visual Studio Code:** Development environment.
- **Git and GitHub:** Version control and project hosting.

## 6. Installation and Requirements

To run the programs, the following software is required:

1. Python 3 installed on the computer.
2. Visual Studio Code.
3. Required Python libraries.

Install the required libraries using:

```bash
pip install numpy scipy matplotlib
```

The `timeit` module is included in Python and does not require separate installation.

## 7. How to Run the Programs

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the required Python program.

For example, to run Task 2:

```bash
python Code/Task_02.py
```

To run Task 20:

```bash
python Code/Task_20.py
```

Replace the task number with the program you want to execute.
